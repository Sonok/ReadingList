# HPC and ML inference

High-performance computing and the systems side of machine learning: computer architecture, parallel and GPU
programming, and making model inference fast.

## Courses

- **CMSC411 Computer Systems Architecture** (University of Maryland, spring 2027)
  Instruction set architecture, pipelining, the memory hierarchy, instruction-level parallelism (branch prediction,
  Tomasulo), and thread-level, data-level, and shared-memory parallelism.
  Text: Hennessy and Patterson, *Computer Architecture: A Quantitative Approach*.

## Reading

- [ ] **Computer Architecture: A Quantitative Approach, 6th edition** by John Hennessy and David Patterson (Tier 2)
  The standard text on how processors and accelerators are designed and measured. Course text for CMSC411.
- [ ] **Programming Massively Parallel Processors: A Hands-on Approach, 4th edition** by Wen-mei Hwu, David Kirk, and Izzat El Hajj (Tier 3)
  The usual introduction to GPU programming: CUDA, parallel patterns, and performance considerations.
- [ ] **Performance Analysis and Tuning on Modern CPUs** by Denis Bakhvalov (Tier 3)
  Measuring and speeding up real code: profiling, CPU microarchitecture, and memory and branch behavior. Free online.

These build on the C and C++ foundation in the [systems track](systems.md).
