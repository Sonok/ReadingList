# Career progression

## Reading

- [ ] **Designing Data-Intensive Applications, 2nd edition** by Martin Kleppmann and Chris Riccomini (Tier 1)
  The standard text on storage, replication, partitioning, and stream processing. Core background for systems interviews and for any infra-heavy dev role.
- [ ] **Computer Systems: A Programmer's Perspective, 3rd edition** by Randal Bryant and David O'Hallaron (Tier 3)
  Fills the low-latency / systems slot. Added 2026-09-29. The memory hierarchy chapter (ch 6) answers the Optiver
  array-vs-skip-list question directly: caches, locality, and why contiguous memory wins. Also covers machine-level code,
  linking, virtual memory, and concurrency. Relevant to quant dev as much as general career. Start with ch 6 if short on time.
